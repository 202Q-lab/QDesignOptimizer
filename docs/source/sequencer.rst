.. _sequencer:

Simulation sequencer
====================

``qdesignoptimizer.sequencer`` queues QDO studies and runs them one at a
time, writing tuned design variables back between them. This page is
``tutorials/example_simulation_sequencer/README.md``; the example
projects it describes are in that folder of the repository.
