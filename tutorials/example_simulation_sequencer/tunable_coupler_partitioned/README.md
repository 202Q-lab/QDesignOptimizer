# Two transmons with a tunable coupler, tuned in partitions

Two fixed-frequency transmons at 4.16 and 4.00 GHz, each read out by its
own resonator (7.12 and 7.07 GHz), coupled through a tunable-coupler
transmon at 5.45 GHz. The chip is tuned in three smaller eigenmode
solves rather than one: each qubit with its resonator, and the coupler
with both qubits. The rounds repeat because the partitions pull on each
other.

The chip is the one of `examples_coupled_transmons_tunable_coupler_chip`,
split as `main_eigenmode_two_qubit_resonator_partitioned.ipynb` splits it.
A report takes this file's heading as the design's name and its first
paragraph as its purpose.
